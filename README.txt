Карта зарядок Кыргызстана — v4

Исправлено: SPARK KG больше не исчезает при выборе CCS2, если GraphQL-фильтр оператора подтверждает соответствие станции.

ВАЖНО: SPARK API ChargingStationsList возвращает ID коннекторов, но не их типы. Дополнительный запрос с connectors.type.in = [C_CCS2] определяет наличие CCS2 на устройстве, а не тип конкретного порта. Устройства без подтверждения CCS2 не будут отображаться по данному фильтру. Данные о других типах разъёмов SPARK пока не получены.

Запуск: node server.mjs
Адрес: http://localhost:3080
Тесты: npm test

Если типы SPARK не удалось загрузить, в строке статуса покажется конкретная ошибка. Список станций останется доступен.

Публикация на tesla.bosh.kg

Ветка main публикуется через GitHub Actions и FTPS в каталог
public_html/tesla.bosh.kg на Fornex. Настройте секреты FTPS_HOST,
FTPS_USER и FTPS_PASSWORD в окружении production. FTP-пользователю
нужен доступ к этому каталогу из корня учётной записи или из public_html.
Для API нужны PHP 8.1 или новее, расширение cURL и Apache mod_rewrite.
Node.js используется для локального запуска и тестирования исходной версии.
